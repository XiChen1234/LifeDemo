# 生活台 · Life Console — 前端页面规划

> 基于 `doc/参考.html` 原型，使用 **Vue 3 + TypeScript + Pinia + Vue Router + ECharts** 重构。
> 当前阶段不连接后端，全部数据来自 `src/mock/` 下的 Mock 数据，后续以 API 层替换。

***

## 1. 技术栈与工程约定

| 项    | 选型                               | 说明                                  |
| ---- | -------------------------------- | ----------------------------------- |
| 框架   | Vue 3 `<script setup lang="ts">` | 组合式 API                             |
| 状态管理 | Pinia                            | 按领域拆分 store，数据从 mock 注入             |
| 路由   | Vue Router                       | 7 个一级页面，`/` 重定向到 `/dashboard`       |
| 图表   | ECharts 5（按需引入）                  | 封装 `VChart` 通用组件，统一主题色与 tooltip 样式  |
| 样式   | 原生 CSS + CSS 变量                  | 沿用原型设计 token，不引入 UI 组件库，保证还原度       |
| 语言   | TypeScript                       | mock 数据与 store 均有类型定义（`src/types/`） |

工程约定：

* 组件命名 PascalCase，目录按「领域」组织。

* 所有文案、数据走 mock，组件只读 store，不直接 import mock。

* 需要新增依赖：`echarts`（其余已在 package.json 中）。

***

## 2. 设计系统（沿用原型 Token）

写入 `src/styles/tokens.css`，作为全局 CSS 变量：

* **底色**：`--bg:#f7f9f8`，卡片 `#ffffff`，次级面 `#fafcfb`

* **文字**：主 `#26302d` / 次 `#6b7570` / 弱 `#a2aaa6`

* **主题色**：薄荷绿 `#55b99a`（主）、`#3e9a7c`（深绿）；辅色黄 `#f3c96a`、蓝 `#78a9dc`、粉 `#e5a3b6`，均有对应 soft 底色

* **语义色**：success `#45a982` / warn `#d49a3a` / danger `#d47474`

* **圆角**：9 / 12 / 16 / 20px；**阴影**：极轻卡片投影

* **字号阶梯**：9–24px；间距阶梯：4 / 8 / 12 / 16 / 22 / 32px

整体气质：清爽、留白充足、低饱和薄荷绿为主色的日式极简 Dashboard。

## 4. 页面结构详拆

### 4.1 首页 `/dashboard`

1. **ViewHead**：标题「首页」+ 日期天气副标题 + 右侧标签「本周第 4 天」
2. **HeroBanner**：问候语 + 每日一句 + chips（连续记录天数 / 本周完成度 / 目标年份），右侧大号日期 `06 / 12`
3. **指标卡 ×4**（grid g4）：睡眠、本月支出、今日步数、连续记录天数（带涨跌标识）
4. **今年的小目标**：纵向进度条列表（读书 / 跑步 / 储蓄 / 旅行，不同配色）
5. **收支趋势（ECharts 双折线，近 6 月）＋ 今天要做（任务清单，可勾选）** — 1.35:1 两栏
6. **生活切片三栏**：支出结构（进度条列表）/ 阅读观影进度 / 最近笔记

### 4.2 健康 `/health`

1. **Hero 组合**：状态卡片（今日状态 + chips）＋ 2×2 mini 卡（睡眠 / 步数，含细进度条）
2. **本周睡眠趋势（ECharts 堆叠面积图：深睡/浅睡/REM）＋ 本月运动时长（堆叠柱状图：跑步/骑行/健身/其他）**
3. **体重曲线（折线）＋ 最近睡眠记录（列表 + 状态 pill）**
4. **习惯打卡**：4 张可点击卡片（喝水/冥想/拉伸/早睡），点击切换打卡状态

### 4.3 财富 `/wealth`

1. **PageBanner**：本月收支健康小结 + chips（总资产/结余/储蓄率）
2. **指标卡 ×4**：总资产 / 本月收入 / 本月支出 / 本月结余
3. **本月收支对比（分组柱状图，按周）＋ 近 6 月支出趋势（折线）**
4. **支出分类占比（环形图 + 中心金额）＋ 储蓄目标进度（年度/月度/连续）**
5. **最近交易（带分类 pill 与正负金额）＋ 预算使用情况（超支变红色）**

### 4.4 工作 `/work`

1. **PageBanner**：今日节奏 + chips（高优数 / 本周 DDL / 专注时长）
2. **六月日历**：自绘月历组件，单元格内渲染事件 pill（高/中/低/DDL 四色），今天高亮
3. **今日待办（按高/中/低优先级分组，可勾选）＋ 右列：即将到期列表 & 项目进度条**

### 4.5 生活与媒体 `/life`

1. **PageBanner**：本月小结 + chips（运动/阅读/观影次数）
2. **指标卡 ×4**：本周游戏时长 / 本月观影 / 本月阅读 / 本月活动次数
3. **月度活动分布（环形图）＋ 内容类型占比（环形图）**
4. **阅读进度 ＋ 观影进度（进度条列表）**
5. **最近完播/读完**：双列列表（类型 pill + 标题 + 日期 + 星级）

### 4.6 笔记 `/notes`

1. **PageBanner** ＋ **紧凑指标行 ×4**（总量 / 本月新增 / 标签数 / 本周编辑）
2. **三栏布局**（168px 目录树 ｜ 1fr 预览 ｜ 232px 侧栏）：

   * 目录树：Inbox / Notes（含 3 个子目录）/ Projects / Archive，带计数，可选中

   * 预览卡：标题 + 标签 + 时间字数 + 正文段落（带高亮小标题样式）+ 底部标签

   * 侧栏：最近笔记列表（点击切换预览内容）+ 标签分布 Top8 条形
3. 交互：点击笔记列表 → 切换预览；点击目录 → 过滤列表（mock 层实现）

### 4.7 设置 `/settings`

1. **PageBanner**（版本 / 主题 / 存储状态）
2. **个人信息卡**：头像 + 昵称 / 目标年份 / 签名（受控输入，写入 store）
3. **主题偏好卡**：亮色/暗色/跟随系统（仅亮色可用，其余 disabled 提示）＋ 关于信息（版本、技术栈、图表方案、更新日期）
4. **数据源配置卡**：财务 API / 健康 API / Obsidian 路径，均为占位「未连接」状态

## 6. Pinia Store 划分（`src/stores/`）

| Store               | 内容                                        |
| ------------------- | ----------------------------------------- |
| `useAppStore`       | 用户信息、问候语、连续天数、最后更新时间、主题偏好                 |
| `useDashboardStore` | 首页指标、年度目标、收支趋势、今日任务、支出结构、阅读观影、最近笔记摘要      |
| `useHealthStore`    | 睡眠趋势/记录、运动时长、体重曲线、习惯打卡（含 toggle action）   |
| `useWealthStore`    | 资产指标、周收支、6 月趋势、分类占比、储蓄目标、交易列表、预算          |
| `useWorkStore`      | 日历事件、待办（按优先级）、即将到期、项目进度（含 toggle action）  |
| `useLifeStore`      | 活动/媒体分布、阅读/观影进度、完播读完列表、生活指标               |
| `useNotesStore`     | 目录树、笔记列表、当前选中笔记、标签分布（含 selectNote action） |

Mock 数据集中在 `src/mock/`（按页面分文件 + `types/index.ts` 定义接口），store 初始 state 从 mock 读取，后续仅需替换为 API 调用。

## 8. ECharts 主题约定

* 统一注册薄荷绿系调色板：`['#55b99a','#78a9dc','#f3c96a','#e5a3b6','#a9cbe8','#cfd8d3']`

* 坐标轴/分割线用 `#edf1ef` / `#a3ada8`，字号 10px

* Tooltip 深色圆角样式还原原型 `.chart-tip`

* 环形图中心显示总额/总数

* 图表高度约定：趋势类 170–200px，环形 180px

## 10. 与原型的差异说明

* 图表由自绘 SVG 改为 **ECharts**，视觉样式对齐原型配色与 tooltip。

* 侧边栏导航改用 `router-link`，切换页面为真实路由跳转（保留淡入动画）。

* 任务勾选、习惯打卡、笔记切换等交互接入 Pinia，状态可持久化到 localStorage（可选，默认开启）。
